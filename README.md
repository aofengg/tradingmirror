# 交易留痕

面向业余股票交易者的极简交易行为记录与复盘微信小程序。

## 技术栈

- 原生微信小程序（WXML / WXSS / JavaScript）
- CommonJS 模块
- Pages → Services → Repository 分层
- 微信云开发登录、云函数与云数据库
- 自定义 TabBar

## 开发前准备

1. 在微信开发者工具中打开本目录。
2. 创建或选择云开发环境。
3. 如需固定环境，在 `miniprogram/config/constants.js` 填写 `CLOUD_ENV`；留空则使用开发者工具当前云环境。
4. 上传并部署 `cloudfunctions/login`、`cloudfunctions/tradeData` 和 `cloudfunctions/reviewAI`，选择「云端安装依赖」。`reviewAI` 实际执行上限设为90秒，不能只依赖本地配置文件。
5. 按 `docs/database-setup.md` 创建数据库集合、索引和只读安全规则。

## 已实现

- 操作前/操作后三步极简记录，原有单条流程保留；
- 新增同页批量录入：多选／手输标的、明确保存、历史补记、持久化重试与撤销；
- 市场大事记：手动录入收盘点位/涨跌幅，按市场、指数、年份查看图示与年表，涨红跌绿；
- 买入、加仓、减仓、清仓动态原因标签；
- 根据原因自动归类「按原计划/临时决定/不确定」；
- 事后「满意/可以接受/懊悔」回看；
- 懊悔原因记录；
- 最近操作列表；
- 基于完整文字记录的AI复盘：最多一条值得延续、一条下次留意；
- 状态变化图：买入／加仓与减仓／清仓分开查看，按周对照当时动因与同一批操作的后来感受，保留全部回看及原记录入口；
- 操作意图与实际执行分离，一键确认是否下单；
- 事后感受时间线，新感受不覆盖历史；
- 未完成记录草稿自动恢复；
- 单条交易记录及关联感受删除；
- 用户数据隔离和云端保存。
- Schema v2 增量迁移与旧数据兼容；
- 云端事务、服务端时间和重复提交保护；
- 市场/资产身份与自动复盘时间窗；
- 游标分页和可重建的周统计快照。
- 操作与回看的弱引导可选备注、截图压缩上传和附件生命周期清理。
- 复盘可查看完整依据和原记录，其他发现按需展开；原有理由/感受查阅保留在次级页面。
- 一条可编辑、可撤回的当前提醒，与首页及相关操作前记录联动。
- 使用 `deepseek-v4.1-flash`，生成与内容复核两次调用；同一数据版本复用结果，不随打开页面重复生成。

## 数据安全

原始记录写入通过 `tradeData`；AI缓存、反馈与提醒通过独立的 `reviewAI` 云函数，均按服务端登录身份隔离。正式环境建议设置为“当前用户只读自己的数据、客户端禁止写入”。本项目不收集券商账户、成交价格和仓位数据，不提供投资建议。
