# 状态变化图：实现与验收基准

2026-10-31。用户已确认示意方向，补充计划/条件动因、买入/加仓与减仓/清仓分组，授权开发并按长期验收标准执行。顶部页面名和底部入口继续为“复盘”，内容大标题为“智能复盘”。

目标：在原有两条发现之后、当前提醒之前，用一张可点选的图连接不同时期的操作动因与同一批操作的后来感受。保留已有AI结论、提醒、历史查阅，不增加记录必填项。

## 数据契约

- 仅统计已执行的买入/加仓或减仓/清仓。按实际执行时间归入上海时区周一开始的一周，缺失时依既有约定回退发生/创建时间。未执行、待确认、非法时间、未来、未知动作分别排除并记录覆盖范围。
- “计划/条件”使用明确理由键：符合计划、逻辑更确定、价格到目标、达到预设目标、持仓逻辑变化、触发风控。其余按所选方向展示怕错过、临时机会、担心回吐、难忍波动和其他理由。临时机会不是情绪强度，按计划不是平静。详情保留原理由及备注。
- 动因各行互斥，合计等于当周该方向的操作数；色深表示当周占比，数字表示次数。没有操作的周为空白，不当作平静或可接受。
- 后来感受按同一批原操作归位，每个操作仅计最近一次有效回看。多次回看不重复计数，明细保留全部历史、日期及懊悔原因。未回看与无法识别的其他感受独立显示。
- 当前周截止查询时刻，未来操作/回看不提前纳入。全部来源完整分页读取；中途失败整体失败。详情15条一页，来源版本变更时拒绝混页，重试从第一页开始。
- 统计与事实摘要使用确定性代码，不新增模型请求或改写AI快照/交易/回看。账户身份由云函数真实登录校验，版本绑定完整有效来源，前端缓存绑定账号、日期及记录修订。
