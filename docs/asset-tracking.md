# 个股持续跟踪实现说明

## 入口

- 记录页保留原时间列表，增加“按时间看／按个股看”。个股视图支持搜索、待办筛选和分页。
- 记录卡片在操作原因下方以小号灰字显示原有操作备注，最多两行，超出省略，完整内容仍在详情页查看；无备注不占位。时间列表（含筛选与待办）展示对应操作备注，个股卡片展示最近一条操作的备注。（2026-10-18：帮助快速回忆当时的决定。）
- 点击个股卡或时间列表中的标的名称，进入个股足迹；保留现有卡片、状态和回看样式。
- 选中标的后展示最近已执行记录和最新感受；从足迹发起记录预填标的。浏览历史后保留步骤与草稿。
- 足迹页菜单提供标的归并与撤销，不修改原始操作及回看。
- 「按个股看」的市场标签可直接点开底部「更正市场」面板。选中后原地更新，碰到目标市场已有相同代码和类型才确认归并。后续仍可从标签重新选择市场。
- 单条和批量保存时按代码或曾用名称精确匹配。唯一匹配沿用卡片当前身份，多项才弹出具体标的选择，无匹配按原有录入规则归类。批量中多个名称指向同一张卡片时，只提交一次并提示。

## 数据

`tradeData` 新增 `listAssetSummaries`、`getAssetHistory`、`getAssetContext`、`mergeAsset` 和 `undoAssetMerge`。
查询用户身份由云函数上下文取得。历史使用 `_id` 键集分批扫描全部未删除记录，不依赖已加载的首屏；返回列表按时间与 ID 复合游标分页，同时间戳不会漏项。超时或读失败返回错误，不把部分扫描伪装成完整历史。

资产映射保存在现有 `user_config.asset_links` 数组中（source/target），事务更新；不需要新增集合。别名经用户确认后映射，撤销移除对应映射。原始标的文本和回看不会被改写。不同已明确市场或资产类型不可归并。

市场更正用 `changeAssetMarket` 写入带 `kind: 'market'` 的独立归组边，原始交易和回看保留。`asset_market_change` 记录最近请求用于幂等；常规别名撤销仅作用于别名边。目标市场已有同代码、同类型卡片时，服务端返回冲突信息，明确确认后才归组。`getAssetContext` 和 `listAssetMatches` 提供精确匹配，单条及批量保存携带最终选择的标的键，新记录保留已确认的市场。旧记录与旧客户端兼容，无需数据迁移。

历史版本会在确认执行时覆盖 `occurred_at`。对 `stage=before` 的原始决定，足迹改用 `recorded_at`／`created_at` 保留原先位置；最近已执行仍按 `executed_at` 选取。无需修改旧数据。

待回看口径与首页保持一致：已执行、没有回看、已达到 `review_due_at`。无持仓或盈亏推断。

## 部署

部署 `cloudfunctions/tradeData`（必须包括 `asset-tracking.js`），再编译小程序。现有项目绑定环境保持不变。
可为 `trade_events` 补充 `_openid` 升序 + `is_deleted` 升序 + `_id` 升序的非唯一索引；本次实现不创建或删除索引。
当前历史规模下采用服务端完整扫描聚合；历史显著增长时应以可重建摘要替代每次全扫描，并保持同一数据口径。遇到云函数超时会展示可重试错误。

- `asset-cloud.test.js`：超过 200 条数据的扫描、用户隔离、事务归并撤销及原记录不变。
- `asset-interactions.test.js`：请求乱序、读取失败、组件卸载、路由编码、草稿冲突和规范化标的提交。
- 全部现有测试继续执行。
- 模拟器使用现有数据核验卡片、足迹和记录提示；不提交测试交易或更改真实执行状态。

## 操作与感受概览

个股足迹页在摘要和详细卡片之间展示双轨概览。操作与每一次回看按各自真实时间倒序排列，最近在上；同一笔操作的多次回看分别编号并连回原操作。已执行操作使用 executed_at，未确认/取消想法使用记录时间；回看使用 reviewed_at，旧数据回退 created_at。无有效日期的节点放在末尾，不补造时间。

概览独立于下方详细卡片的筛选与排序。首次展示最近 6 个节点，可展开更早节点，也可收起整个概览。可见范围外的原操作不绘制虚假连线，回看说明仍展示对应操作日期和类型；点击任意节点打开原记录。满意/可以接受/懊悔沿用绿/灰/柔和红标签，未回看状态仍保留在操作节点。

数据沿用现有只读接口：完整分页读取该个股（包含别名归组）的操作，按每批 20 个操作读取回看；回看使用 _id 游标逐页查询，避免相同时间戳丢记录。仅查询当前用户未删除记录，任何分页失败显示重试，不把部分结果当完整足迹。页面返回、下拉刷新及归并变化会重读；卸载和过期响应不能覆盖新页面。无需新增集合或云函数部署。

验证：tests/asset-overview.test.js 覆盖倒序、执行时间、同笔多次回看、归属连线、渐进展开、同时间戳分页、旧操作最近回看、失败与过期请求。
